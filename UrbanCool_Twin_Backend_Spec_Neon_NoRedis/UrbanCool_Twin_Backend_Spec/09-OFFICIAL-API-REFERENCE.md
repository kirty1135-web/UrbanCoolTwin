## Verification policy

Before production:

1. verify endpoint is currently live
2. verify current collection/resource IDs
3. verify authentication
4. verify quotas
5. verify licensing/attribution
6. record provider version/processing version

Do not rely on undocumented URLs or stale resource IDs.
